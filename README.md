# AikoFlow

Le multitâche façon Hyprland, pour Mac (Windows ensuite) : tes fenêtres se rangent toutes seules côte à côte, sur 9 pages qu'on change au clavier, instantanément.

## Raccourcis (touche de base : ⌃ ⌥, modifiable)

| Raccourci | Action |
|---|---|
| ⌃ ⌥ 1 … 9 | Aller à la page |
| ⌃ ⌥ ⇧ 1 … 9 | Envoyer la fenêtre sur la page |
| ⌃ ⌥ ← ↑ → ↓ | Passer à la fenêtre voisine |
| ⌃ ⌥ ⇧ ← ↑ → ↓ | Déplacer la fenêtre |
| ⌃ ⌥ ⌘ ← ↑ → ↓ | Agrandir / réduire |
| ⌃ ⌥ ⇥ | Vue d'ensemble des pages |
| ⌃ ⌥ F | Plein écran (dans AikoFlow) |
| ⌃ ⌥ T | Fenêtre flottante / rangée |
| ⌃ ⌥ S | Côte à côte ↔ l'une sur l'autre |
| ⌃ ⌥ R | Rééquilibrer |
| ⌃ ⌥ P | Activer / couper AikoFlow |

À la souris : glisse une fenêtre sur une autre pour les échanger, tire un bord pour redimensionner.

## Sans conflit avec macOS

- Coupé (⌃ ⌥ P ou la barre des menus), AikoFlow libère tous ses raccourcis et rend toutes les fenêtres visibles.
- Les bureaux de Mission Control ne sont pas touchés : les pages AikoFlow vivent dans le bureau actuel.
- ⌘ ⇥ vers une fenêtre d'une autre page y emmène directement.
- Calculette, Réglages Système… restent flottantes ; d'autres applis peuvent être ajoutées ou ignorées.

## Installation (Mac)

Double-clic sur `macos/Installer AikoFlow.command`, puis autoriser AikoFlow dans Réglages Système → Confidentialité et sécurité → Accessibilité.
